System Overview

About FinScore 360

An advanced, user-input-driven financial evaluation platform combining statistical learning with sound lending prudence.

Our Mission

FinScore 360 was built to democratize institutional-grade financial risk assessment for borrowers and financial planners. By marrying modern predictive algorithms with classical affordability math, the platform offers an immediate, objective appraisal of loan eligibility, debt strain, and financial resilience.

Strict Privacy & Data Ethics

FinScore 360 never pre-fills financial values, never silently pulls data from external datasets for user predictions, and never shares your sensitive income parameters. Every single ratio, score, and recommendation is calculated purely from what you explicitly input in your current session.

The 4 Core Pillars

1. Loan Approval Prediction

Employs a trained machine learning ensemble in the backend to assess historical loan issuance patterns against your financial and demographic profile.

2. EMI Calculator

Executes exact reducing-balance interest computations to deliver transparent amortization, monthly installment figures, and debt-to-income benchmarks.

3. Financial Risk Assessment

Produces the proprietary 0–100 FinScore Risk Score, evaluating total debt-to-income burden, existing commitments, leverage multiples, and income stability.

4. Personalized Financial Tips

Generates targeted, pragmatic financial recommendations focused on debt reduction, tenure adjustments, or credit optimization tailored to your entered numbers.

Developer Instructions

Running FinScore-360 in VS Code on Windows

To run the native Python/Flask application locally on your Windows workstation:

# 1. Create a Python Virtual Environment
python -m venv venv

# 2. Activate Virtual Environment (Windows PowerShell / CMD)
venv\Scripts\activate

# 3. Install Required Dependencies
pip install -r requirements.txt

# 4. Train Models & Generate Preprocessing Artifacts
cd ml
python train_models.py
python evaluate_models.py
cd ..

# 5. Start the Flask Server
python app.py

# 6. Open in Browser
http://127.0.0.1:5000

The machine learning training step reads data/raw/loan_data.csv, cleans features, benchmarks models, and exports the selected inference pipeline to ml/saved_models/ without exposing data to end users.
